# fpga-
本装置设计并实现了一套以视觉图形分析为核心的信号控制装置，采用“OpenMV 摄像头采集分析＋ZYNQ7020 异构主控＋显示屏交互”的三级架构。OpenMV 负责现场图像采集与底层图形分析，完成色块识别、轮廓检测、AprilTag 标记定位等视觉算法，提取目标坐标、面积、角度等特征数据，并通过串口上传至 ZYNQ7020；ZYNQ7020 的 PS（ARM）端完成识别数据的解析、阈值判定与控制策略运算，PL（FPGA）端以硬件并行方式生成高实时性控制信号，二者经 AXI 总线高速交互；淘金驰显示屏实时回显原始画面、识别框、目标数据与系统状态，支持现场调参。装置可实现目标追踪、色块定位触发、标记物位置闭环控制等功能，对外输出电平、PWM 与脉冲等多类信号。
